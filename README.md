# MCP

A collection of [Model Context Protocol (MCP)](https://modelcontextprotocol.io) servers.

| Project | Description |
|---|---|
| [sql-investigator](sql-investigator/) | Read-only MCP server (C# / .NET 10) that lets Claude Code investigate a Microsoft SQL Server database during debugging, alongside your frontend and backend code. Includes a T-SQL validator, always-rollback queries, read-only impersonation, an audit log, and live diagnostics (blocking, slow queries). |

Each project has its own README with setup and usage instructions.
